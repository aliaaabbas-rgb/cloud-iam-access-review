# Cloud IAM Access Review & Least Privilege Audit

A practical cloud security and GRC portfolio project demonstrating Identity and Access Management (IAM) access reviews, least privilege assessment, security finding documentation, remediation tracking, and management reporting.

## Project Objectives

- Review user, guest, and service accounts.
- Identify excessive and inappropriate access privileges.
- Detect inactive accounts and missing MFA.
- Evaluate privileged and shared service accounts.
- Document security findings and remediation actions.
- Define approved roles using a least privilege matrix.
- Present key IAM risk indicators through a dashboard.

## Workbook Contents

### 1. Access Review

Reviews 12 simulated cloud accounts and records:

- Account type and assigned role
- Privilege level
- MFA status
- Last login date
- Account status
- Access finding
- Risk level
- Recommended action

### 2. IAM Findings

Documents identified IAM security issues, including:

- Excessive privileges
- Missing MFA
- Dormant accounts
- Former employee access
- Shared privileged accounts
- Guest access without expiration
- Excessive service and database permissions

Each finding includes business impact, recommended remediation, owner, target date, and status.

### 3. Role Matrix

Defines approved roles, privilege levels, permitted actions, restricted actions, review frequency, and accountable role owners.

### 4. Dashboard

Provides a management summary of:

- 12 accounts reviewed
- 2 critical risks
- 5 high risks
- 2 accounts without MFA
- 6 open findings
- 3 findings in progress

The dashboard also includes risk distribution and remediation status charts.
